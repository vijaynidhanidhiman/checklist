# Checklist Spring Boot App

A simple Spring Boot application to manage a checklist.

## Endpoints

- `GET /api/checklist` - Get all items
- `POST /api/checklist` - Add a new item
- `PUT /api/checklist/{id}` - Update an item
- `DELETE /api/checklist/{id}` - Delete an item

## Running

```bash
./mvnw spring-boot:run
```
